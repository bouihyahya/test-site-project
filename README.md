# Agence Al-Ataa : site statique (sans Firebase)

- `index.html` : le site complet (données intégrées dans le fichier)
- `images/`, `videos/` : photos, logo, affiche du programme, vidéos
- Modifier le contenu : ouvrir `…/#admin`, changer les champs, cliquer « Télécharger index.html »,
  puis remplacer `index.html` dans le dépôt GitHub.
- Ajouter une photo : la placer dans `images/` et écrire son chemin (ex. `images/photo.jpg`) dans le tableau de bord.
